プロジェクトは、複数のセッションを案件や目的ごとにまとめるための単位です。Speclane Studio では、過去の会話を引き継いで続きの作業を開始したり、関連するセッションを一か所に集めて管理したりできます。作業フォルダや Git リポジトリとは役割が異なるため、ファイルの整理とは別に使ってください。

## 続きの作業を開く

左側の会話一覧から続けたいセッションを選びます。会話の内容と作業場所を確認したうえで、新しい依頼を送ってください。同じ案件でも目的が大きく変わる場合は、新しいチャットを作成すると経緯を追いやすくなります。

<Tip>
  以前に別の AI ツールで行った会話を引き継ぎたい場合は、先に[セッションをインポート](/guides/import-sessions)してください。インポートしたセッションもプロジェクトに追加できます。
</Tip>

## プロジェクトを作成してセッションを追加する

<Steps>
  <Step title="新しいプロジェクトを作成する">
    サイドバーの「新しいプロジェクト」をクリックし、案件名など分かりやすい名前を入力します。名前はあとから変更できます。
  </Step>
  <Step title="セッションをプロジェクトに追加する">
    追加したいセッションのメニュー（「…」）を開き、「プロジェクトに追加」を選択します。複数のセッションを同じプロジェクトにまとめることができます。
  </Step>
  <Step title="プロジェクトから会話を開く">
    サイドバーのプロジェクト一覧から対象プロジェクトを展開し、セッションを選んで作業を再開します。
  </Step>
</Steps>

## プロジェクトの初期値を設定する

プロジェクトのメニューにある「プロジェクト設定」では、そのプロジェクト内で新しいセッションを開始するときのデフォルト値を設定できます。毎回同じホスト・ディレクトリ・AI を選ぶ場合に便利です。

<CardGroup cols={3}>
  <Card title="ホスト" icon="server">
    接続先のマシンやサーバーを指定します。新しいセッション開始時に自動で選択されます。
  </Card>
  <Card title="作業ディレクトリ" icon="folder-open">
    AI が参照するデフォルトのフォルダパスを設定します。リポジトリのルートを指定するのが一般的です。
  </Card>
  <Card title="AI モデル" icon="robot">
    Claude Code や Codex など、使用する AI エージェントの初期値を選択します。
  </Card>
</CardGroup>

<Note>
  設定した初期値はあくまでデフォルトです。セッション開始画面に値が入力されていても、送信前に内容を必ず確認してください。
</Note>

## 会話をアーカイブする

一覧から不要になったセッションをアーカイブできます。アーカイブしたセッションは「設定 → アーカイブ」から確認・復元できます。作業中のセッションを誤ってアーカイブしないよう注意してください。

<Warning>
  **プロジェクトを削除すると、そのプロジェクトに含まれるすべてのセッションもアーカイブされます。**確認画面で対象をよく確認してから操作を進めてください。プロジェクトの整理を、作業フォルダの削除として使わないでください。ファイルシステム上のフォルダやリポジトリには影響しませんが、セッション履歴の管理に影響します。
</Warning>

他の利用者に会話を見てもらいたい場合は、プロジェクトへの追加とは別に[会話の共有](/guides/sharing)を使ってください。
