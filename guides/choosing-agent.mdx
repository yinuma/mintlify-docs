Speclane Studio では、接続先のホストに用意された複数のAIを共通の画面から利用できます。チャットを開始する前に、エージェント・モデル・権限モードの3つを確認しておくと、作業がスムーズに進みます。ホストや認証の状態によって選択肢が変わるため、別のホストへ切り替えたときも同様に設定を見直してください。

## 選ぶ項目の違い

エージェント・モデル・権限モードはそれぞれ役割が異なります。下表で各項目の意味と確認ポイントを把握しておきましょう。

| 項目 | 決めること | 確認する点 |
|------|-----------|-----------|
| エージェント | 作業を進めるAIの種類や実行方式（ハーネス） | チームで使うAIか、ホストで準備済みか |
| モデル | AIの判断・文章生成を担うモデル | 選択肢が表示されるときに指定。「デフォルト」は実行環境の標準設定 |
| 権限・承認のモード | どの操作で利用者の確認を求めるか | 今回の作業に必要な範囲に合っているか |

<Info>
  画面に「ハーネス」と表示される場合は、AIを動かす実行方式を指します。同じAI系列でも、実行方式によって設定項目や利用できる操作が変わります。
</Info>

## 作業開始前の設定手順

<Steps>
  <Step title="ホストを選ぶ">
    新しいチャットを開き、作業するホストを選択します。ホストが変わると利用できるAIとモデルの候補も変わります。
  </Step>
  <Step title="エージェントを選ぶ">
    エージェントの選択欄で、利用するAIを選びます。Claude Code や Codex など、表示された候補から選択してください。
  </Step>
  <Step title="モデルを選ぶ">
    モデルの設定が表示された場合は、使用するモデルを指定します。「デフォルト」を選ぶと、その実行環境の標準モデルが使われます。
  </Step>
  <Step title="権限・承認モードを確認する">
    権限や承認の設定を読み、作業フォルダと依頼内容に対して適切な範囲かを確認してから作業を開始します。
  </Step>
</Steps>

## 「設定が必要」が表示されたら

そのホストでCLIの導入やサインインが完了していない状態です。ブラウザで Speclane Studio にサインインすることと、ホスト側でAIを使えるようにすることは**別の準備**です。

<Warning>
  「設定が必要」と表示されたまま作業を開始することはできません。画面に表示されたセットアップ案内に従うか、管理者に依頼してください。
</Warning>

対応手順は以下のとおりです。

<AccordionGroup>
  <Accordion title="CLIが未導入の場合">
    ホストのセットアップ画面に表示されるコマンドを実行して、CLIをインストールします。完了後、ページを再読み込みして選択肢が更新されたことを確認します。
  </Accordion>
  <Accordion title="サインインが必要な場合">
    表示された認証手順に従い、ホスト上でサインインを行います。`claude login` や `codex auth` など、AIによってコマンドが異なります。
  </Accordion>
  <Accordion title="管理者に依頼が必要な場合">
    組織のポリシーでAIへのアクセスが制限されている場合は、管理者にプロビジョニングを依頼してください。
  </Accordion>
</AccordionGroup>

## 未設定のエージェントを非表示にする

選択肢が多くて選びにくいときは、設定で表示を絞ることができます。

<Steps>
  <Step title="設定を開く">
    画面右上のアカウントメニューから **設定 → 外観** を開きます。
  </Step>
  <Step title="未設定のハーネスを非表示にする">
    「未設定のハーネスを非表示」をオンにします。選択欄に準備済みのエージェントだけが表示されるようになります。
  </Step>
</Steps>

<Note>
  この設定は選択欄の**表示を変えるだけ**です。AIのインストールや削除は行いません。
</Note>

## まず調べてもらいたいとき

編集を始める前に現状を把握したい場合は、読み取り専用の依頼から始めましょう。次のようなプロンプトが参考になります。

```text
注文確認画面の現在の動作を調べてください。
送料が決まる条件と、関連する仕様書を説明してください。
今回は調査だけにし、ファイルの編集は行わないでください。
```

<Tip>
  選んだエージェントに読み取り専用モードや計画モードがある場合は、その説明を確認してください。チャットでの依頼と、実際の操作権限の設定は役割が異なります。
</Tip>

別のAIの考え方も見たいときは、[会話を複製して別案を並行検討する](/guides/fork-session)を活用してください。
