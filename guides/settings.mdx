Speclane Studio の設定画面では、表示言語やテーマ、操作方法、外部サービスとの連携を管理します。初回利用時や環境が変わったときに確認しておくと、スムーズに作業を進められます。

<Tabs>
  <Tab title="言語">
    ## 日本語・英語を切り替える

    チャット画面上部の言語切替から「日本語」または「English」を選択します。切り替えは即時反映され、メニューやボタンの表示が選択した言語に変わります。

    <Info>
      このドキュメントの操作名は日本語表示を基準にしています。英語表示に切り替えた場合は、メニュー名が異なります。サインイン画面にも同様の言語切替があります。
    </Info>
  </Tab>
  <Tab title="外観">
    ## テーマと表示を調整する

    「設定 → 外観」で、以下の項目を設定できます。

    <ParamField path="テーマ" type="選択肢">
      **ライト / ダーク / システムに合わせる**の 3 種類から選択します。「システムに合わせる」を選ぶと、OS のダーク/ライトモード設定に自動で追従します。
    </ParamField>

    <ParamField path="文字サイズ" type="選択肢">
      サイドバーや本文の文字サイズを調整します。長時間の作業では読みやすいサイズに設定してください。
    </ParamField>

    設定を変更したらチャット画面に戻り、会話エリアと右パネルが読みやすい状態か確認してください。

    <Note>
      ホストアプリケーションがテーマを制御している場合は、そのアプリケーションの案内に従ってください。Studio の外観設定が上書きされることがあります。
    </Note>
  </Tab>
  <Tab title="キーボード">
    ## キーボード操作を確認する

    「設定 → キーボードショートカット」で、現在有効な操作一覧を確認できます。よく使う操作を事前に把握しておくと作業効率が上がります。

    | 操作 | 確認すべき理由 |
    |---|---|
    | メッセージ送信 | Enter キーで即送信されるか確認する |
    | 改行 | Shift+Enter など、送信とは別のキーを把握する |
    | 生成の停止 | AI の出力を途中で止める操作を覚えておく |
    | 画面切替 | チャットとエディタを素早く切り替えられる |

    <Tip>
      日本語入力（IME）を使う際は、変換確定の Enter キーとメッセージ送信の Enter キーを区別してください。変換が確定してから送信操作を行うと、意図しない送信を防げます。
    </Tip>
  </Tab>
  <Tab title="GitHub 連携">
    ## GitHub に接続する

    リポジトリのコピーや、「履歴」パネルからのプッシュ・プルを使う場合は、あらかじめ GitHub との接続を設定しておく必要があります。

    「設定 → サンドボックス連携」を開き、GitHub の接続状態を確認します。未接続の場合は画面の案内に従って認証を完了させてください。

    <Note>
      **AI モデルへのアクセス認証と、GitHub へのアクセス認証は別の設定です。** AI が正常に動作していても、GitHub への接続が完了していなければリポジトリへのプッシュ・プルは行えません。それぞれ個別に設定してください。
    </Note>

    接続後も、作業環境から対象リポジトリへの適切なアクセス権が付与されている必要があります。権限エラーが発生した場合は、リポジトリの設定や組織のポリシーを確認してください。

    <Warning>
      GitHub 連携が利用できない場合は、サーバー側の設定が必要な可能性があります。個人での設定で解決しない場合は、管理者に利用可否を確認してください。
    </Warning>
  </Tab>
</Tabs>
