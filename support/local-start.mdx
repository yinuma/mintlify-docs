このページは、**Speclane Studio の CLI がすでに導入されている環境**を対象にしています。インストール元や AI の認証方法は、導入を担当した管理者の案内に従ってください。まだインストールが済んでいない場合は、先に管理者へ確認してからこのページに戻ってください。

<Note>
  Speclane Studio の基盤 CLI コマンド名は `omnigent` です。他製品のインストール手順と混同しないよう、Speclane として導入した環境でのみ実行してください。
</Note>

## 起動の手順

<Steps>
  <Step title="ターミナルを開く">
    お使いの OS のターミナルアプリケーション（macOS なら「ターミナル」または「iTerm2」、Windows なら「Windows Terminal」など）を起動します。
  </Step>

  <Step title="サーバーとホストをバックグラウンドで起動する">
    次のコマンドを実行します。

    ```bash
    omnigent start --server ''
    ```

    `--server ''` はローカルをサーバーとして使用するための引数です。このフラグを省略すると、組織のリモートサーバーに接続しようとします。ローカルで単独起動する場合は必ず指定してください。

    ソースチェックアウトの仮想環境（`.venv`）を使っている場合は、`Speclane-Studio` フォルダ内で次のコマンドを実行します。

    ```bash
    .venv/bin/omnigent start --server ''
    ```
  </Step>

  <Step title="表示された URL をブラウザで開く">
    コマンドの出力にサーバー URL が表示されます。標準設定では `http://127.0.0.1:6767` です。そのアドレスをブラウザのアドレスバーに入力して開いてください。

    <Note>
      `127.0.0.1` はコマンドを実行した端末自身を指します。**別のパソコンやスマートフォン**から接続する場合は、このアドレスは使えません。組織のサーバー URL を管理者に確認してください。
    </Note>
  </Step>

  <Step title="起動状態を確認する">
    次のコマンドで、サーバーとホストがそれぞれ正常に起動しているか確認します。

    ```bash
    omnigent server status
    omnigent host status
    ```

    - **サーバー**のステータスが `running` であることを確認します。
    - **ホスト**のステータスが `online` であることを確認します。

    複数の接続先が表示される場合は、今使用する URL に対応するものを確認してください。

    仮想環境を使っている場合は、`omnigent` を `.venv/bin/omnigent` に読み替えてください。

    ```bash
    .venv/bin/omnigent server status
    .venv/bin/omnigent host status
    ```
  </Step>
</Steps>

## 作業を終えて停止する

Speclane Studio の使用が終わったら、バックグラウンドで動いているサーバーとホストを明示的に停止します。**ブラウザを閉じるだけでは停止しません。**

進行中の作業と結果を確認したうえで、次のコマンドを実行してください。

```bash
omnigent stop
```

<Warning>
  停止中はAIの作業を続けられません。長時間の処理が走っている場合は、完了または中断を確認してから停止してください。
</Warning>

仮想環境を使っている場合は次のコマンドを使います。

```bash
.venv/bin/omnigent stop
```

## `--server ''` フラグについて

`--server ''` は、接続先サーバーとして**ローカル（同一マシン）**を使用するよう指定するフラグです。

| フラグの指定 | 動作 |
| --- | --- |
| `--server ''`（空文字） | ローカルにサーバーを立ち上げて接続する |
| フラグなし | 設定ファイルに記載された組織のサーバーに接続しようとする |

ローカルで完結した開発や動作確認をする際は、常に `--server ''` を指定してください。

## 組織のサーバーに接続する場合

組織の共有サーバーを使う場合は、このページのコマンドではなく、管理者から案内されたホスト接続手順に従ってください。ローカル起動のコマンドでは組織のサーバーへは接続しません。

<Tip>
  起動が確認できたら、[最初のチャットを始める](/start/quickstart)へ進んでください。
</Tip>
